# Unconfused UI - Master Component Taxonomy & Roadmap

Este documento define a taxonomia oficial de 24 categorias de componentes do ecossistema **Unconfused UI**.

---

## 1. Foundations / Base (EM IMPLEMENTAÇÃO)
- `Box`
- `View`
- `Container`
- `Stack`
- `HStack`
- `VStack`
- `Row`
- `Column`
- `Center`
- `Spacer`
- `Divider`
- `AspectRatio`
- `Absolute`
- `SafeArea`
- `KeyboardAvoidingView`
- `ScrollView`
- `HorizontalScroll`
- `Portal`

---

## 2. Tipografia
- `Text`, `Heading`, `Title`, `Subtitle`, `Label`, `Caption`, `Paragraph`, `Link`, `Code`, `Blockquote`, `TruncatedText`, `GradientText`

## 3. Buttons
- `Button`, `IconButton`, `ButtonGroup`, `FloatingActionButton`, `LinkButton`, `CloseButton`, `BackButton`, `SubmitButton`

## 4. Inputs
- `Input`, `TextInput`, `Textarea`, `SearchInput`, `PasswordInput`, `NumberInput`, `EmailInput`, `PhoneInput`, `CodeInput`, `PinInput`, `OTPInput`, `CurrencyInput`, `MaskedInput`

## 5. Selection
- `Checkbox`, `CheckboxGroup`, `Radio`, `RadioGroup`, `Switch`, `Toggle`, `ToggleGroup`, `SegmentedControl`, `Select`, `MultiSelect`, `Combobox`, `Autocomplete`, `Picker`, `Slider`, `RangeSlider`

## 6. Formulários
- `Form`, `FormField`, `FormLabel`, `FormControl`, `FormDescription`, `FormMessage`, `FormError`, `FormSection`, `FieldGroup`

## 7. Feedback
- `Alert`, `AlertDialog`, `ConfirmDialog`, `Toast`, `Snackbar`, `Banner`, `Callout`, `Notice`, `ErrorMessage`, `SuccessMessage`, `WarningMessage`, `InfoMessage`, `Progress`, `ProgressBar`, `ProgressCircle`, `Spinner`, `LoadingIndicator`, `Skeleton`

## 8. Overlay / Dialog
- `Modal`, `Dialog`, `AlertDialog`, `ConfirmDialog`, `Drawer`, `Sheet`, `BottomSheet`, `ActionSheet`, `Popover`, `Tooltip`, `ContextMenu`, `DropdownMenu`

## 9. Navigation UI
- `Tabs`, `Tab`, `TabBar`, `TopTabs`, `BottomTabs`, `Breadcrumb`, `NavigationBar`, `NavigationRail`, `Navbar`, `Header`, `Toolbar`, `AppBar`, `Drawer`, `Sidebar`, `Pagination`, `Stepper`

## 10. Lists
- `List`, `ListItem`, `ListSection`, `ListHeader`, `ListFooter`, `VirtualList`, `FlatList`, `SectionList`, `Grid`, `GridItem`, `Table`, `TableRow`, `TableCell`, `TableHeader`

## 11. Cards / Surfaces
- `Card`, `CardHeader`, `CardBody`, `CardFooter`, `Surface`, `Panel`, `Paper`, `Tile`, `FeatureCard`, `ActionCard`

## 12. Avatar / Identidade
- `Avatar`, `AvatarImage`, `AvatarFallback`, `AvatarGroup`, `UserAvatar`, `Profile`, `PresenceIndicator`

## 13. Badges / Status
- `Badge`, `StatusBadge`, `Tag`, `Chip`, `Pill`, `Indicator`, `Dot`, `Counter`

## 14. Menus
- `Menu`, `MenuItem`, `MenuGroup`, `MenuSeparator`, `Dropdown`, `DropdownMenu`, `ContextMenu`, `CommandMenu`, `CommandPalette`

## 15. Date / Time
- `DatePicker`, `TimePicker`, `DateTimePicker`, `Calendar`, `CalendarRange`, `MonthPicker`, `YearPicker`, `DateInput`, `TimeInput`

## 16. Media
- `Image`, `ImageBackground`, `Avatar`, `ImageViewer`, `ImageGallery`, `Carousel`, `Video`, `AudioPlayer`, `MediaPlayer`, `Thumbnail`, `Icon`

## 17. Loading
- `Spinner`, `ActivityIndicator`, `LoadingIndicator`, `ProgressBar`, `ProgressCircle`, `Skeleton`, `SkeletonText`, `SkeletonAvatar`, `SkeletonCard`, `Shimmer`

## 18. Empty States
- `EmptyState`, `NoResults`, `NotFound`, `ErrorState`, `OfflineState`, `LoadingState`

## 19. Accordion / Disclosure
- `Accordion`, `AccordionItem`, `Collapsible`, `Disclosure`, `DisclosureGroup`, `Expandable`, `Tree`, `TreeItem`

## 20. Data Visualization
- `Chart`, `LineChart`, `BarChart`, `AreaChart`, `PieChart`, `DonutChart`, `RadarChart`, `ProgressChart`, `Sparkline`, `Gauge`

## 21. Gestures / Interação
- `Pressable`, `Touchable`, `Swipeable`, `SwipeActions`, `Draggable`, `Droppable`, `Resizable`, `PanGesture`, `LongPress`, `DoubleTap`, `PinchZoom`, `PullToRefresh`

## 22. Layout Avançado
- `Stack`, `HStack`, `VStack`, `Grid`, `Masonry`, `Wrap`, `Flow`, `AspectRatio`, `Center`, `Absolute`, `Overlay`, `Layer`, `Spacer`, `Divider`, `Separator`

## 23. Componentes Específicos para Mobile
- `KeyboardAvoidingView`, `SafeAreaView`, `StatusBar`, `KeyboardAccessory`, `BottomTabBar`, `FloatingActionButton`, `PullToRefresh`, `SwipeActions`, `ActionSheet`, `ShareButton`, `HapticButton`

- `LoginForm`, `SearchBar`, `CommandPalette`, `Pagination`, `DataTable`, `FilterBar`, `FilterSheet`, `DateRangePicker`, `FileUploader`, `ImageUploader`, `PasswordField`, `OTPField`, `VerificationCode`, `UserMenu`, `NotificationCenter`, `ProfileMenu`, `SettingsList`, `SettingsSection`, `PricingCard`, `StatsCard`, `MetricCard`, `DashboardCard`
